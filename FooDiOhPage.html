Foo-Di-Oh

This game obviously takes inspiration from another popular card game. But the actual design and gameplay are fully original and creative.

Play Game

Project Overview

Before I made this game I was feeling very inspired to make a card game. So, I decided to make one using a card game I used to play as a kid as inspiration. Only in the looks of the game though. Everything else is wholly original and unique.

My friends and I really like playing this game because it's silly and fun, and we like having a good time while playing some cards. Since we play the game occasionally, I will sometimes open back up the project and add in new cards and features.
